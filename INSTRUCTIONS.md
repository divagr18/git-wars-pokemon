# Pokemon Git Wars: The Indigo League Challenge

## Welcome, Trainer!

This is a Git-based puzzle challenge where you'll become the Pokemon League Champion by mastering Git operations.

## Rules

1. **Follow the story**: Read the markdown file matching each branch name (e.g., on `ash` branch, read `ash.md`)
2. **Collect badges**: Each successful merge earns you a gym badge and reveals a digit of the Champion Code
3. **Resolve conflicts**: Every merge will have conflicts - choose wisely based on the instructions!
4. **No cheating**: Don't peek at other branches until you're directed there
5. **Track your code**: The `code.md` file contains your 8-digit Champion Code

## Goal

Merge all branches into `main` and obtain the complete 8-digit Champion Code.

## How to Play

1. Start on the `main` branch
2. Read `main.md` for your first instructions
3. Follow the story from branch to branch
4. Merge branches as instructed, resolving conflicts correctly
5. Your final code in `code.md` is your Champion Code

## Submission

When you've completed the challenge:
1. Fork this repository
2. Complete the challenge
3. Submit your forked repo link along with your Champion Code

## Git Commands You'll Need

```bash
git checkout <branch>      # Travel to a new location
git merge <branch>         # Battle/challenge
git log                    # Check your journey
git reset --hard HEAD~1    # Heal/recover from mistakes
```
